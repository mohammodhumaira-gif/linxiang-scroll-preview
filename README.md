# 临湘行卷

把本目录中的 index.html、.nojekyll 和整个 assets 文件夹放到 GitHub 仓库根目录，提交到 main。在仓库 Settings → Pages 中选择 Deploy from a branch，再选择 main 和 /(root)。部署完成后，从 Pages 设置页打开预览网址。

如果要放进已有仓库，可以把上述文件放进 docs 文件夹，再选择 main 和 /docs。

[GitHub 官方发布设置说明](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

画卷、地形及水系为《临湘：重启》的游戏概念设计。
